# Transaction History Service\n\nThis service provides an API for bank customers to view their detailed transaction history, with filtering capabilities and an option to download statements.\n\n## Features\n\n*   Retrieve transaction history for a given account.\n*   Filter transactions by date range, transaction type (credit/debit), and amount.\n*   (Future) Download transaction history as a PDF.\n\n## Setup Instructions\n\n1.  **Clone the repository:**\n    ```bash\n    git clone https://github.com/p67428378-afk/Banking-System.git\n    cd Banking-System\n    ```\n\n2.  **Create a virtual environment and install dependencies:**\n    ```bash\n    python -m venv venv\n    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`\n    pip install -r requirements.txt\n    ```\n\n3.  **Database Setup:**\n\n    This service expects a PostgreSQL database. Ensure you have PostgreSQL running and create a database (e.g., `bank_db`).\n\n    Update the `DATABASE_URL` in a `.env` file (create one from `.env.example`):\n    ```dotenv\n    DATABASE_URL="postgresql://user:password@localhost:5432/bank_db"\n    SECRET_KEY="your_secret_key_here"\n    ```\n\n    The application will automatically create the `accounts` and `transactions` tables on startup if they don't exist.\n\n4.  **Run the application:**\n    ```bash\n    python main.py\n    ```\n    The API will be available at `http://127.0.0.1:5000` (default Flask port).\n\n## API Endpoints\n\n### Get Transaction History\n\n`GET /transactions/<account_id>`\n\nRetrieves a list of transactions for a specific account, with optional filters.\n\n**Path Parameters:**\n\n*   `account_id` (UUID): The unique identifier of the customer's account.\n\n**Query Parameters:**\n\n*   `start_date` (YYYY-MM-DD, optional): Start date for filtering transactions. Defaults to 12 months ago.\n*   `end_date` (YYYY-MM-DD, optional): End date for filtering transactions. Defaults to today.\n*   `type` (string, optional): Filter by transaction type. Accepted values: `CREDIT`, `DEBIT`.\n*   `min_amount` (float, optional): Minimum transaction amount.\n*   `max_amount` (float, optional): Maximum transaction amount.\n\n**Example Request:**\n\n```\nGET /transactions/a1b2c3d4-e5f6-7890-1234-567890abcdef?start_date=2023-01-01&end_date=2023-03-31&type=DEBIT&min_amount=10.00\n```\n\n**Example Response (200 OK):**\n\n```json\n[\n  {\n    "account_id": "a1b2c3d4-e5f6-7890-1234-567890abcdef",\n    "amount": "50.00",\n    "balance_after_transaction": null,\n    "currency": "USD",\n    "description": "Online Purchase",\n    "merchant_name": "Amazon",\n    "transaction_date": "2023-03-15T10:00:00",\n    "transaction_id": "f1e2d3c4-b5a6-9876-5432-10fedcba9876",\n    "transaction_type": "DEBIT"\n  }\n]\n```\n\n**Error Responses:**\n\n*   `400 Bad Request`: Invalid date format, start date after end date, invalid amount format, etc.\n*   `404 Not Found`: No transactions found for the given criteria.\n\n## Running Tests\n\nTo run the unit and integration tests, use pytest:\n\n```bash\npytest test_transactions.py\n```\n
